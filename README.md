# CuisineSnap AI

CuisineSnap AI is an AI-powered application developed as a Final Year Project for a Bachelor of Science in Computer Science.

The system is designed to generate recipe suggestions using food images and available ingredients while also providing food assessment and cooking guidance.

## Features

- Food image-based recipe recommendation
- Ingredient-based recipe suggestions
- Food assessment and cooking guidance
- User authentication
- Admin panel
- Recipe management
- Database-driven application
- Responsive web interface

## Technologies Used

- Python
- Flask
- Machine Learning
- Convolutional Neural Networks (CNN)
- Natural Language Processing (NLP)
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure

- `admin/` – Admin module and routes
- `auth/` – User authentication
- `main/` – Main application logic
- `templates/` – HTML templates
- `static/` – CSS, JavaScript, images, and assets
- `migrations/` – Database migrations
- `app.py` – Application entry point
- `models.py` – Database models
- `train_model.py` – Model training logic
